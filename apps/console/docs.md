# Console Architecture

## Application layers

src/app/
    Application routes and pages.

src/components/
    Reusable UI components.

src/features/
    Feature-oriented frontend modules.

src/lib/
    Frontend utilities and integrations.

src/hooks/
    Reusable React hooks.

src/types/
    Frontend type definitions.

src/config/
    Frontend configuration.

## Current phase

Scaffold only.

UI implementation, API integration, authentication, authorization, state management, and production behavior will be engineered later.
