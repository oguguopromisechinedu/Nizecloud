# Repository Structure

NizeCloud is organized as a monorepo.

## apps

User-facing NizeCloud applications.

## services

Independent backend platform capabilities.

Each service owns its own domain and API boundary.

## packages

Reusable libraries, SDKs, clients, types, configuration, and shared utilities.

## infrastructure

Infrastructure definitions for local, development, staging, and production environments.

## docs

Architecture, API, security, development, and operational documentation.

## tests

Integration, end-to-end, and contract testing.

## scripts

Repository-level automation.
